THE PASS — SIX DIRECTIONS
Colour on top, code in the middle, ad on white
No card, no plate, no container. The state is the top of the page — amber for Booked, green for Live — the header carries only the lot name, and the code sits straight on the colour. From the middle down it is one white surface with the ad running the full width of it, the way the live build already runs its rail. The six differ in one thing each: where the colour stops and how it meets the white. Alternating amber and green so both palettes read; either substitutes into any of them.
